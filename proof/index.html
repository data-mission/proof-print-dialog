The format

The print dialog has not
meaningfully changed
since 1995.

Windows 95 shipped a print dialog with a printer dropdown, a copies spinner, a page-range field, and a preview thumbnail about a hundred pixels wide. Thirty-one years later you are still looking at the same four controls and the same useless thumbnail — and still finding out what actually printed by walking to the tray.

What it hides: a page carrying one orphaned footer line looks exactly like a full page at that size. So you print it. The dialog has all the information needed to warn you and has never once used it.
